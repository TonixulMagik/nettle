## What Nettle reads

On a server it is added to, Nettle stores message text from **ticket channels only**, and only
to build the transcript that the server's own staff receive when a ticket is closed. It does not
log your server's normal channels and it does not read direct messages. Where activity levels
are switched on, it checks how long a message is and then discards the text without saving it.

One feature runs on the developer's own server only: mentioning the bot sends that message to
Google's Gemini API to generate a reply. It never runs anywhere else. The full detail, including
that feature, is in the Privacy Policy, section 4.
