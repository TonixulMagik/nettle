self-assignable roles, giveaways and polls.

These pages are served through GitHub Pages so they stay reachable at a stable public URL.

## What Roost reads

Roost reads messages **inside ticket channels only**, and only to build the transcript that a
server's own staff receive when a ticket is closed. It does not read your server's normal
channels and it does not read direct messages. The full detail is in the Privacy Policy.
